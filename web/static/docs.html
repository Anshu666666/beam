Quick Start Walkthrough

Get up and running in under 30 seconds.

1

Download Binary

Download beam.exe to your folder (or use PowerShell 1-liner):

irm .../beam.exe -OutFile "beam.exe"
2

Open Terminal

Open PowerShell or Command Prompt in the folder containing beam.exe.

cd ~/Downloads
3

Run Instant Demo

No URL needed! Automatically runs an 8-worker stream against the sample asset:

.\beam.exe -demo
4

Custom Download

Pass any direct URL supporting HTTP Range (RFC 7233) with custom worker pools:

.\beam.exe -url <URL> -w 8 -c 16
📁

Where do downloaded files get saved?

By default, when -o is omitted, Beam extracts the filename from the URL and saves it directly into your current terminal directory (e.g. C:\Users\YourName\Downloads\filename.zip). Upon completion, Beam prints the exact Saved to: <absolute path> in bright cyan. You can override this at any time using -o "C:\path\to\my_file.zip".

Command-Line Flag Reference

Comprehensive reference for all CLI arguments supported by Beam:

Flag Type Default Description
-url <string> String Required* Target file URL to download. Can also be passed directly as a positional argument: beam <URL>.
-demo Boolean false Executes an instant demonstration download using the official 50 MB sample asset with 8 workers and 16 chunks.
-o <path> String auto-derived Destination file path on disk. If omitted, automatically derived from the URL path.
-w <int> Integer 4 Number of concurrent Goroutine workers in the bounded pool (e.g. -w 8 or -w 16).
-c <int> Integer 4 Total number of byte-range partitions to divide the file into (e.g. -c 16 or -c 32).
-v / -version Boolean false Prints engine version (e.g. Beam v1.0.0) and exits.
-help / help Boolean false Displays the complete interactive ASCII banner, usage summary, and examples.
